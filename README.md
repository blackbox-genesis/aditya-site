# aditya-site
Personal research website focused on computational systems biology, biological robustness and synthetic circuit modeling.

## Running the site

The site is a Next.js app with a scroll-driven 3D cell (three.js).

```bash
npm install
npm run dev        # http://localhost:3000, reloads as you edit
```

Production build:

```bash
npm run build
npm start
```

Photos shown on the site live in `public/images/` (`nibb.jpeg`, `gcsb.jpg`, `fibt.jpg`); rebuild after replacing them.
